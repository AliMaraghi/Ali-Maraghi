APEX Digital Twin - Phase 1: one room, one avatar (a synthetic disc, not a real likeness - no identity-preserving face is authorized or implemented here), spatial audio via the real Web Audio API (PannerNode, panningModel: 'HRTF', distanceModel: 'inverse'), and gaze-responsive gain. Move the mouse over the room to change listener orientation (a proxy for gaze - there is no eye-tracking hardware in this test environment); the avatar's glow and the audio gain both respond to how directly the listener "looks" at it.

HONEST SCOPE: this is a real, runnable Web Audio implementation of the spatial-audio primitive (subsystem D) - it is NOT the ABX perceptual test itself. That test requires an independent human listener, with no briefing, judging avatar direction from audio alone over headphones, ≥8/10 trials - something only a real person can do. This file is the thing that test would be run against; the trial itself is owner-gated (see the session report for the exact procedure).
