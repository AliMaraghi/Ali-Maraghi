# Persona style file - example

Copy this to `runtime/inbox/persona_style.md` on the server and fill it in. That folder is
never committed, so your real voice samples and protected terms stay out of the repository.
The Constitutional Critic (`core/apex/persona_twin.py`) reads it before any draft is proposed,
and the local model is given everything except the red lines when it drafts.
Lines in (brackets) are placeholders and are ignored.

## Tone
- Direct, warm, a little dry
- Specific over general; one concrete detail beats three adjectives

## Vocabulary
- Plain words: "use" not "utilise", "help" not "facilitate"
- (words you actually say a lot)

## Sentence rhythm
- Mostly short sentences, then one longer one that carries the thought
- (anything else you notice about how you write)

## Humour
- Understated; never exclamation marks to signal a joke

## Never say
- circle back
- touch base
