## Decisions

1. Keep the current kernel, domains and durable journal. Kit database paths,
   schemas and enum domains are incompatible; no migration or second runtime.
2. Retain a hard £0 paid budget. Reference mutable ceilings, human strings and
   boolean approvals cannot authorize real spending or actions.
3. Adapt OWP's dynamic axes and coverage concepts into strict existing contracts.
   Accept arbitrary bounded source families/geographies/industries, record scope
   omissions, never label empty searches as market opportunity. No network fetch.
4. Reject reference queue/worker/gateway imports after five reproduced defects.
   Build future workers only with attempt tokens, transactionally coupled audit,
   stop enforcement and concurrency/recovery tests.
5. Keep logical planes visible in traceability. Do not introduce four services or
   eighteen model calls before evidence justifies their cost and failure surface.
6. No new model/agent/API integration. All automated criticism is a deterministic
   checklist; model agreement would still not be independent verification.

Review-kit descriptions of their own state are historical claims. In particular,
its claimed signed baseline is not available: BASELINE.json is an unsigned local
observation, not an independent attestation. Current approval does not cover
production, purchases, paid calls, personal accounts or employer data.
